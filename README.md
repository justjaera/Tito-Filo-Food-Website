# Made With Love Filipino Kitchen

Responsive beige-and-brown made-to-order Filipino food website for GitHub Pages.

## Before publishing
The site currently uses the sample phone number `(630) 936-6837`.

1. In `index.html`, replace every `+16309366837‎` with your real number using country code + digits only.
2. In `index.html`, replace `(630) 936-6837` with the number format you want visitors to see.
3. In `script.js`, replace `const BUSINESS_PHONE = "16309366837‎";` with your real number.

Then upload all files to the root of your GitHub repository.
